# Okane

A long-term AI portfolio manager living inside your Obsidian vault.

Nick reads your research, forms conviction slowly, and does nothing most of the time. He manages a virtual $10,000 portfolio with 3–10 positions, strict kill conditions on every holding, and a mistake ledger that compounds analytical judgment over time.

Inspired by the investment philosophy of **Nick Sleep**.

---

## How It Works

Okane runs as a **Claude Code agent** with custom skills and slash commands. You feed it fundamental research — earnings transcripts, 10-K filings, analyst notes — and Nick decides when to act.

The loop is deliberately slow:

```
Research → Read → Think → (Maybe) Act → Record
```

Daily checks are banned. Nick moves on conviction or kill condition breach, not noise.

## Quick Start

### 1. Add research to the Knowledge Base

Drop files into `knowledge_base/` following the naming conventions:

| Folder | What goes here | Naming |
|--------|---------------|--------|
| `transcripts/` | Earnings calls, investor days | `AAPL-2025-01-28-transcript.md` |
| `filings/` | 10-K, 10-Q reports | `AAPL-2024-10-01-10K.md` |
| `articles/` | Analyst reports, research notes | `AAPL-2025-03-15-moat.md` |
| `theses/` | Auto-generated by Nick — don't edit manually | `AAPL.md` |

Plain text is fine. Copy-paste works. Longer is better than shorter.

### 2. Run the commands

| Command | When | What happens |
|---------|------|-------------|
| `/nick-init` | Once, at the start | Reads entire KB, forms theses, deploys $10,000 across 3–10 stocks |
| `/nick-weekly` | Every weekend | Scans new KB inputs, checks kill conditions, acts only if triggered |
| `/nick-quarterly AAPL` | After earnings | Deep-reads new filings for a ticker, delivers thesis verdict |
| `/watchlist-manager` | Anytime | Add, remove, or update tickers on Nick's monitoring list |

### 3. Let Nick work

After initialization, the cycle is:

- **Weekly** — run `/nick-weekly` to check for kill condition breaches
- **Quarterly** — run `/nick-quarterly <TICKER>` after each earnings release
- **Ongoing** — keep dropping research into `knowledge_base/`

## Key Files

| File | Purpose |
|------|---------|
| `portfolio.md` | Current holdings, cash balance, allocations |
| `WATCHLIST.md` | Tickers Nick is monitoring but hasn't invested in |
| `Z.md` | Mistake ledger — every broken thesis with reflection (append-only) |
| `knowledge_base/` | Research library Nick reads before every decision |

---

## Nick's Rules

1. **Do nothing most of the time** — acts only on deep conviction or kill condition breach
2. **Deep reading first** — reads every source document in full before forming a view
3. **Kill conditions are mandatory** — every position has explicit exit criteria
4. **Intellectual honesty** — says "I don't know" rather than guessing
5. **Blind to your real portfolio** — analyzes only what's in the Knowledge Base

---

## Skills

Nick operates through six custom skills defined in `.claude/skills/`:

| Skill | Purpose |
|-------|---------|
| `read-knowledge-base` | Scans and digests research documents from the KB |
| `generate-thesis-and-kill-conditions` | Writes structured investment thesis with mandatory exit criteria |
| `portfolio-allocator` | Manages position sizing within the $10,000 portfolio |
| `evaluate-triggers` | Cross-references news against active kill conditions |
| `update-memory-ledger` | Appends reflections to `Z.md` when theses are proven wrong |
| `watchlist-manager` | Manages the tickers Nick is monitoring |
