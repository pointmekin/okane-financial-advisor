# Okane

Two AI trading agents living inside your Obsidian vault.

**Nick** — a long-term equity portfolio manager inspired by Nick Sleep. Reads fundamental research, forms conviction slowly, and does nothing most of the time. Manages a virtual $10,000 portfolio with 3–10 positions and strict kill conditions on every holding.

**FX** — a forex swing trader. Monitors macro context and technical setups on major pairs. Trades with predefined entry, stop, target, and invalidation. Can be flat. Acts only when macro bias and chart structure agree.

---

## How It Works

Both agents run as **Claude Code agents** with custom skills and slash commands. You feed them research; they decide when to act.

The loop is deliberately slow:

```
Research → Read → Think → (Maybe) Act → Record
```

Daily price checks are banned for Nick. FX checks in daily but trades only on genuine setups.

## Quick Start — Nick (Equity)

### 1. Add research to Nick's Knowledge Base

```
agents/nick/knowledge_base/
├── transcripts/   AAPL-2025-01-28-transcript.md
├── filings/       AAPL-2024-10-01-10K.md
├── articles/      AAPL-2025-03-15-moat.md
└── theses/        (auto-generated by Nick — don't edit manually)
```

### 2. Run Nick's commands

| Command | When | What happens |
|---------|------|-------------|
| `/nick-init` | Once, at the start | Reads entire KB, forms theses, deploys $10,000 across 3–10 stocks |
| `/nick-weekly` | Every weekend | Scans new KB, checks kill conditions, acts only if triggered |
| `/nick-quarterly AAPL` | After earnings | Deep-reads new filings, delivers thesis verdict |

## Quick Start — FX (Forex Swing)

### 1. Add research to FX's Knowledge Base

```
agents/fx/knowledge_base/
├── macro/     ECB-2026-04-10-statement.md
├── pairs/     EURUSD/EURUSD-2026-05-01-technicals.md
├── calendar/  calendar-2026-05-10.md
├── plans/     (auto-generated by FX — don't edit manually)
└── articles/  general-2026-05-01-dollar-outlook.md
```

### 2. Run FX's commands

| Command | When | What happens |
|---------|------|-------------|
| `/fx-init` | Once, at the start | Reads KB, builds pair-bias matrix, initializes watchlist (no positions opened) |
| `/fx-daily-brief` | Up to once per day | Scans new KB and calendar, updates biases, flags event windows |
| `/fx-setup-scan EURUSD` | On-demand | Grades current setup quality (A/B/C) with macro+technical reasoning |
| `/fx-trade EURUSD` | When a grade-A/B setup exists | Writes plan, runs risk checks, opens position |
| `/fx-weekly` | Every weekend | Reviews open positions, tightens stops if appropriate |
| `/fx-close EURUSD` | When a trigger fires | Closes position, appends closure note, logs mistakes if applicable |

## Nick's Rules

1. **Do nothing most of the time** — acts only on deep conviction or kill condition breach
2. **Deep reading first** — reads every source document in full before forming a view
3. **Kill conditions are mandatory** — every position has explicit exit criteria
4. **Intellectual honesty** — says "I don't know" rather than guessing
5. **Blind to your real portfolio** — analyzes only what's in the Knowledge Base

## FX's Rules

1. **No plan, no trade** — every entry requires a written plan with stop, target, and invalidation
2. **Risk discipline** — max $100 at risk per trade, max $500 total across all positions
3. **Stops are sacred** — can only be tightened, never widened after entry
4. **No correlated overlap** — no positions that create duplicate directional exposure
5. **Event-window discipline** — no new entries within 24h of high-impact events
6. **Clean stops are not mistakes** — only rule violations go into Z.md
